# 0.1.0a4

Compatibility fixes for the public EXL3 installation path.

- Pass CPU Hadamard group IDs to the public ExLlamaV3 BF16 API while retaining GPU IDs for the independent M32 module.
- Provide an explicit compatibility option for older experimental BF16 wheels.
- Keep B12X optional when its route was not explicitly selected.

The public ExLlamaV3 and M32 source builds passed. Package checks passed 68 tests with 3 skipped. A TP2 service without B12X captured all seven configured graph sizes and passed 40/40 tasks with no new failures; exact output agreement was 39/40. This does not establish a performance gain or validate a public rebuild of the MXFP6/FlashInfer dependencies. See [public installation](../public-install.md) for the dependency contract and [validation](../validation.md) for the test scope.
