# vLLM 0.29.0 native MXFP6 profile

The active profile ships in the Python wheel under
[`src/vllm_mach/mxfp6/profile`](../../src/vllm_mach/mxfp6/profile).
Install it with `vllm-mach-install --apply` after installing the pinned dependencies.
See the [installation guide](../../docs/installation.md).

The former EXL3/GDN overlays are removed; their source and release-specific
instructions remain available in Git history. Do not combine them with this profile.
